# Vela www

The source for [vela.space](https://vela.space): one full-screen landing hero,
no application surface.

The site remains a static public front door; it does not own scientific state
or implement a unified Frontiers product. The wider direction and repository
responsibilities live in the [autonomous-science programme
vision](https://github.com/williamjblair/autonomous-science/blob/master/VISION.md)
and [repository
map](https://github.com/williamjblair/autonomous-science/blob/master/docs/REPOSITORY_MAP.md).

```bash
bun install --frozen-lockfile
bun run verify
bun run serve
```
