# vela.space product boundary

`vela.space` is Vela's public institutional front door. It is not the Problems
product, a protocol explorer, a documentation mirror, or a sign-in surface.

The opening is one viewport tall and never scrolls. It contains the retained
painting, the Vela mark, a link to `problems.science/problems`, and a link to
the exact signed Vela 0.977.6 release. The page name remains available to
screen readers and crawlers even though the opening has no visible headline.

Historical editorial routes redirect to `/`; former product and documentation
routes redirect to their canonical external owners. Git history, not a live
compatibility layer, retains removed essays and bands.
